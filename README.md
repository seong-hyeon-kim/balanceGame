# 밸런스 게임 – 요즘 SNS 인기 주제

틱톡·인스타 등 SNS에서 자주 언급되는 밸런스 게임 주제(연애·썸, 음식, 마라맛 극한선택, 갓생·일상, 돈·직장, 디지털·SNS 습관)를 모은 웹 페이지입니다.

## 실행 방법

빌드 과정이 필요 없는 순수 HTML/CSS/JS 프로젝트입니다. 로컬에서 정적 파일 서버로 열면 됩니다.

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

또는 `index.html`을 브라우저로 바로 열어도 동작합니다.

## 구성

- `index.html` – 페이지 구조
- `style.css` – 스타일 (모바일 우선 반응형)
- `questions.js` – 카테고리·질문 데이터 및 성향 태그, 성향 타입 설명
- `app.js` – 게임 로직 (카테고리 선택, 투표, 성향 분석, 결과 공유)
- `kakao-config.js` – 카카오톡 공유용 JavaScript 키 설정 파일

## 주요 기능

- 카테고리별(연애·썸 / 음식 / 마라맛 극한선택 / 갓생·일상 / 돈·직장 / 디지털·SNS) 밸런스 게임
- 선택 시 누적 선택 비율 표시 (브라우저 `localStorage` 기준)
- 질문 순서 섞기
- 게임이 끝나면 선택 패턴을 분석해 "모험형 / 안정형 / 감성형 / 이성형 / 자유형 / 노력형" 중
  하나의 성향 결과를 보여줌 (성향별 비율 그래프 포함)
- 결과를 텍스트로 공유(클립보드 복사 또는 OS 공유 시트)
- 카카오톡 공유 버튼으로 친구에게 결과 전송

## 카카오톡 공유 설정

카카오톡 공유 버튼을 실제로 동작시키려면 본인의 카카오 JavaScript 키가 필요합니다 (자세한 안내는
`kakao-config.js` 파일 상단 주석 참고).

1. https://developers.kakao.com 에서 애플리케이션 생성 후 **JavaScript 키**를 복사
2. `kakao-config.js`의 `KAKAO_JS_KEY` 값에 붙여넣기
3. 카카오 개발자 콘솔의 [앱 설정 > 플랫폼]에서 실제 배포 도메인(예: GitHub Pages 주소)을
   Web 플랫폼으로 등록

키를 설정하지 않으면 카카오톡 공유 버튼을 눌렀을 때 자동으로 결과 텍스트를 클립보드에 복사하는
방식으로 대체됩니다.
